# Screenshots

The pictures the [README](../../README.md#screenshots) shows. Everything in them is made up: a
demo home with the projects of an imaginary company (Acme), stand-in agents that replay scripted
conversations (as those in `script/test-agents` do), and local stand-ins for GitHub and Linear.
No real account, project or person is in them.

| File | What it shows |
|---|---|
| `today.png` | Today: the sidebar, what needs you, what comes up, usage, and the manager |
| `one-worktree.png` | One worktree with three sessions (Claude, Codex, a shell) and its pull request |
| `terminal.png` | A Claude session in terminal view |
| `manager-draws.png` | The manager explaining a fix with a small diagram |
| `voice.png` | Voice: the manager's orb listening |
| `board.png` | The Board: Linear tickets by status, and reviews asked of you |
| `pull-requests.png` | Pull requests: yours and the ones waiting for your review |
| `usage.png` | Usage: each account's limits and tokens per day |

Take any new one the same way, never from your own home: keep every screenshot free of real
projects, tickets, accounts and personal data. About 1600 pixels wide is enough.
